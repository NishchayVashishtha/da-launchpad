# DA Launchpad

Static learning site for aspiring data analysts (Astro + MDX + React islands + Tailwind v4).

- `npm install`, then `npm run dev` / `npm run build` / `npm run preview`
- `npm run validate` runs every SQL/Python practice solution; `npm run audit` checks content structure.
- Set `SITE_BASE=/repo-name/` for sub-path hosting. Content rules and schemas: see `CLAUDE.md`.
